Uma loja virtual completa projetada para entregar uma experiência de navegação rápida (SPA) utilizando a força do PHP com o ecossistema reativo do Vue.

## 🚀 Tecnologias e Stack

- **Backend:** Laravel 8 (**PHP 7.4**) e arquitetura **MVC**
- **Frontend:** **Vue.js 2.5** acoplado via Inertia.js
- **Banco de Dados:** **MySQL**
- **Gestão de Pacotes:** Composer e NPM
- **Pagamentos:** Integração com Mercado Pago

## 💻 Sobre o Projeto

Este projeto foi construído seguindo o padrão de arquitetura **MVC** (Model-View-Controller) do Laravel, demonstrando a criação fluida de uma aplicação web sem a necessidade de construir uma API RESTful separada, usando o **Inertia.js** como ponte direta entre o Laravel e o Vue.

Ele conta com:

- **Sistema de avaliações:** Para feedback dos produtos.
- **Ativação de conta por E-mail:** Garantindo segurança no cadastro.
- **Webhook para o Mercado Livre:** Detectando automaticamente o status dos pedidos.
- **Backoffice completo:** Gestão administrativa total da loja.
- **Totalmente Responsivo:** Design adaptado perfeitamente para **Mobile**.
- Checkout final de compra e configuração flexível do gateway de recebimentos.

Para rodar o projeto localmente, basta atender os requisitos básicos (Node.js v14+ e Composer), clonar o repositório, instalar as dependências via NPM e Composer, e executar as _migrations_ do Laravel.
