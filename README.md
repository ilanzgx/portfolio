# Portfolio

Portfólio pessoal e repositório de artigos criado com foco em performance e minimalismo.
Construído com [Astro](https://astro.build/), [Tailwind CSS](https://tailwindcss.com/) e [TypeScript](https://www.typescriptlang.org/).

## 🚀 Inicialização Local

1. Instale as dependências:

```bash
bun install
```

2. Inicialize o servidor de desenvolvimento:

```bash
bun run dev
```

Visite `http://localhost:4321` para ver a aplicação rodando.
